*[STDF]: Standard Test Data Format — the binary format ATE testers write test results in
*[ATDF]: ASCII Test Data Format — the human-readable text equivalent of STDF
*[ATE]: Automated Test Equipment — the tester that measures each die and assigns its bins
*[hbin]: Hard bin — the physical sort category the handler assigns, and what yield is based on
*[sbin]: Soft bin — the finer software classification recording why a die passed or failed
*[Cpk]: Process capability index — capability accounting for how far off-centre the process sits
*[Ppk]: Process performance index — the long-term form of Cpk
*[WASM]: WebAssembly — the compiled format the Rust parsers run in inside a browser
*[CORS]: Cross-Origin Resource Sharing — the browser rule governing requests to another origin
